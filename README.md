# TP IoT Conso - ESP32 (ESIEA)

Binôme 25 : TAGNON & KPANOU

## Matériel
NodeMCU ESP32, breadboard, bouton, résistance, LED intégrée, LDR, potentiomètre, LM35, BME680, LCD I2C.

## Utilisation
Le code compilé est celui de `src/main.cpp`. Pour tester un exercice, copier son fichier de `exercices/` dans `src/main.cpp`, puis :

    pio run --target upload
    pio device monitor
